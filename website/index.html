    Additional media

    Bonus disc, four art cards

    • Format, type and edition

      DVD, Blu-ray or 4K. Movie, series, documentary, concert, cartoon, anime or music. Standard, steelbook, collector’s, limited, director’s cut or extended.

    • Barcode

      Save the EAN and search by it later, like when you’re in a shop wondering whether you already own that one.

    • Availability

      Available, on delivery, borrowed out, given to a friend, lost or damaged. No more guessing where the case went.

    • Audio and subtitles

      Tag every track with its language. Your preferred language is highlighted everywhere, so you can see at a glance what you can watch.

    • Watched, rating and notes

      Tick it off, rate it from one to five stars, and leave yourself a note for next time.

    • Everything else

      Free-form notes, plus a field for extras like bonus discs, booklets and art cards.

    Your collection stays in your house

    Home Media runs on your own hardware and keeps everything in one SQLite file in the folder you mount. There’s no account to create and nothing syncs to anyone’s cloud.

    • Back up from Settings as a SQL dump or a copy of the database file
    • Export the whole collection to CSV whenever you like
    • The default admin password has to be changed on first sign-in
    • It won’t start in production with the default JWT secret
    • Writes are rate limited per client IP

    Running in about a minute

    Choose your options, copy the compose file and start the container. All you need is a machine with Docker.

    How will you reach it?

    JWT secret

    Generated in your browser. It never leaves this page.

    docker-compose.yml 
    services:
  homemedia:
    image: rustydaemon/homemedia:latest
    container_name: homemedia
    restart: unless-stopped
    ports:
      - '9812:8080' # host:container
    environment:
      - JWT_SECRET=replace-with-a-long-random-string
      - ENABLE_GUEST_MODE=true
      - ENABLE_REQUESTS=true
    volumes:
      - /mnt/mystorage/homemedia:/app/data

    1. Save the file

      Name it docker-compose.yml and put it wherever you keep your other stacks.

    2. Start the container

      Run docker compose up -d in the same folder.

    3. Sign in and change the password

      Open http://your-server:9812 and sign in as admin with password admin. You’ll pick a new password straight away.

    Questions

    Something else on your mind? Open an issue on GitHub.

    Does it play my movies?

    No. Home Media is a catalog for the physical discs on your shelf, not a media server. It sits happily next to Plex, Jellyfin or a plain old Blu-ray player.

    What does it cost?

    Nothing. Home Media is open source under the GNU AGPL-3.0 license, and all of the code is on GitHub.

    Where is my data stored?

    In a single SQLite database inside the folder you mount at /app/data. Copy that folder and you’ve copied everything. You can also make backups and CSV exports from Settings.

    Can I import the list I already have?

    Not yet. CSV import is planned. CSV export already works, so your data is never locked in.

    Can other people use it?

    Yes. With guest mode on, anyone you share the address with can choose Browse as Guest. Guests can look around and search, but they can’t add, edit or delete anything.

    What hardware does it need?

    Anything that runs Docker on x86-64, which covers most NAS boxes, mini PCs and home servers. It’s a single small Go binary with SQLite, so it barely registers. For ARM boards like a Raspberry Pi, build the image from source with the included Dockerfile.

    Does it send my data anywhere?

    No. The only outside request it makes is to Docker Hub, to check for a newer version so it can tell you about updates. The answer is cached for four hours. There’s no analytics or tracking.

    Is it ready for my whole collection?

    It’s in active development and some features may still change, so keep backups. That takes two clicks in Settings.
